── ZKP Design Properties ──

    1. Verification = proof + public inputs ONLY
       The verifier never sees GPS coordinates.
       It checks: "given these public inputs, is this proof valid?" → true/false

    2. Circuit code is policy-agnostic
       Same circuit works for ANY geofence (Paris, Tokyo, São Paulo...)
       Only the public inputs change (center_lat, center_lon, radius).
       No recompilation, no redeployment — just new policy parameters.

    3. Everything can live on a public ledger
       ✓ Circuit code (open source — Plonky2, MIT/Apache 2.0)
       ✓ X.509 certificate (contains geo-id-hash + proof-hash)
       ✓ ZKP proof (fetched from zkp-proof-uri in cert)
       ✗ GPS coordinates — NEVER exposed, by mathematical guarantee

    Full transparency + full privacy. That's the ZKP value proposition.
